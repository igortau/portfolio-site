# Как системный аналитик использует AI

AI-инструменты постепенно становятся частью повседневной работы системного аналитика.

Я использую LLM для:

- анализа документации;
- генерации SQL-запросов;
- подготовки черновиков требований;
- анализа API;
- семантического поиска по документам;
- генерации тестовых сценариев.

Особенно интересны локальные LLM:
- Ollama
- OpenWebUI
- RAG
- PostgreSQL + pgvector

Это позволяет строить приватные AI-системы без отправки данных во внешние облака.
